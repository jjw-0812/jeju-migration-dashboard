# 제주 인구이동 대시보드

정적 HTML과 Google Apps Script로 제주와 다른 시도 간 전입·전출·순이동을 표시합니다.

## 조회 기능

기본은 시작연월·종료연월로 선택한 기간만 조회합니다. 비교 메뉴에서 2개년 또는 3개년을 선택하면 1년 전·2년 전의 같은 기간도 함께 조회합니다.

- 전체 연령, 청년(19세~39세), 10대~90대, 남성·여성·전체 필터
- 선택 기간의 전입·전출·순이동 합계
- 월별 표와 순이동 차트, 시도별 누계, CSV 내보내기
- 단일 월, 여러 해에 걸친 기간, 12개월을 넘는 기간 지원

연령은 만 나이입니다. 90대는 90~99세이며, 전체 연령에는 0~9세와 100세 이상도 포함됩니다. 연령·성별을 바꿀 때는 이미 받은 자료로 다시 계산하므로 추가 API 호출이 없습니다.

시작월과 종료월을 모두 포함합니다. 선택 가능한 범위는 2024년 1월부터 지난달까지이며, 지난달까지 선택 가능하다는 것이 통계 공표를 보장하지는 않습니다. 미공표·자료 없음·조회 오류·연령 필드 누락은 `—`로 표시하고 0명으로 합산하지 않습니다. 필수 월 하나라도 누락되면 해당 누계를 비웁니다. 종료월이 시작월보다 빠른 경우 조회하지 않습니다.

2026년 7월 이전 광주(29)·전남(46)을 합산해 이후 전남광주통합특별시(12)와 같은 지역 범위로 집계합니다. 코드 12와 2026년 9월 양방향 조회는 이 프로젝트에서 실제 API로 확인했습니다. 변경 시점은 2026년 7월로 적용합니다.

이 화면 단순화는 기존 API를 재사용하므로 Apps Script를 다시 교체할 필요가 없습니다.

## 2개년·3개년 동일기간 비교

비교 메뉴의 기본값은 **선택 기간만**입니다. **2개년 비교**는 선택 기간과 1년 전, **3개년 비교**는 선택 기간과 1년 전·2년 전을 비교합니다. 예를 들어 2026년 7~8월의 3개년 비교는 2026·2025·2024년 7~8월입니다. 연도를 넘는 기간도 각 월에서 정확히 1년·2년을 빼서 맞춥니다.

비교를 켜면 연도별 전입·전출·순이동 누계, 월별 비교 차트와 표를 표시합니다. 비교 지표 선택으로 전입·전출·순이동을 바꿀 수 있습니다. 연령·성별은 모든 기간에 동일하게 적용합니다. 요약 카드·지도·시도별 표는 선택한 기준기간입니다. CSV에는 기준기간 자료와 비교 기간별 누계·월별 값이 모두 포함됩니다.

지원 시작인 2024년 이전 비교 월은 API에 요청하지 않으며 `—`로 표시합니다. 누락 월이 있으면 해당 기간 전체 누계도 비웁니다. 겹치는 기간의 동일 월은 한 번만 요청하고 재사용합니다. `comparison.js`는 비교 화면·CSV를 담당하며 파일 변경 시 해당 스크립트 URL의 `v` 값을 갱신하세요.

## 청년(19세~39세)

청년 선택은 요청한 제주 청년 기준인 만 19세부터 39세까지를 포함합니다. 서버에서 나이별 19세 값과 20대·30대 값을 더해 별도 `youth1939: [남성, 여성]` 필드로 반환합니다. 기존 `youth`(20~39세)는 이전 클라이언트 호환용으로 유지하고, 새 화면에서는 사용하지 않습니다. 성별·기간·지역별 합계, 지도, CSV에 같은 기준이 적용됩니다.

이 항목을 실제 데이터로 사용하려면 아래의 v7 `Code.gs`로 원격 Apps Script를 업데이트해야 합니다. v6 응답에는 19세를 분리할 수 있는 값이 없어 화면에서 추정하지 않습니다. 새 필드가 없는 경우 합계를 비우고 연결 업데이트 안내를 표시합니다. 스크립트 교체와 새 버전 배포를 완료한 뒤 대시보드를 새로고침하세요. 기존 API 키 속성은 유지합니다. 현재 기본 연결 주소에서 v7을 확인했고, 실제 2026년 9월 전입 청년 합계는 19~39세 890명(기존 20~39세 842명), 서울은 246명(기존 237명)으로 브라우저 표시까지 검증했습니다.

## 연월 다이얼

시작연월·종료연월 버튼을 누르면 연도·월 휠 선택 창이 열립니다. 마우스 휠·드래그·터치 스와이프, 방향키·Home/End·PageUp/PageDown을 지원합니다. 선택 완료를 눌러야 값이 반영되고, 취소·Escape·바깥 클릭은 기존 값을 유지합니다. 선택 창을 닫으면 원래 버튼으로 포커스가 돌아갑니다.

시작연월은 종료연월까지, 종료연월은 시작연월부터 지난달까지로 선택 범위를 제한합니다. 2024년 1월 이전이나 지난달 이후는 선택할 수 없습니다. 조회 중에는 두 선택 버튼도 잠깁니다. 실제 요청값은 기존 `YYYY-MM` 형식을 유지하며 서버 코드는 변경하지 않습니다.

`month-dial.js`가 동작을, `theme.css`가 휠의 가운데 선택 행·양끝 흐림 효과를 정의합니다. 선택 행의 높이는 두 파일 모두 44px입니다. 동작 코드를 변경하면 `index.html`의 해당 스크립트 `v` 값도 SHA-256 앞 12자리로 갱신하세요.

## 화면 테마와 폰트

사용자가 제공한 제주도 인구플랫폼 스크린샷을 참고한 흰색·파란색 테마입니다. 조회 영역은 옅은 파랑, 조회 버튼·차트·강조색은 파랑, 요약 카드 상단은 파란 그라데이션입니다. 지도 전입·전출의 빨강·파랑 의미는 유지합니다.

한글 폰트는 화면과 비슷한 인상의 **Noto Sans KR**를 사용합니다. 참조 사이트의 실제 폰트는 확인되지 않았습니다. 가변 WOFF2 폰트를 `assets/fonts/`에 자체 호스팅하므로 외부 폰트 CDN 요청은 없습니다. 원본과 가공 내역·OFL 라이선스는 [assets/fonts/README.md](assets/fonts/README.md)에 보존했습니다.

스타일은 `theme.css`에 모았습니다. CSS를 변경하면 `index.html`의 `theme.css?v=…`를 파일 SHA-256 앞 12자리로 갱신하세요. 새 폰트 파일은 내용 해시를 파일명에 포함합니다.

## 시도별 지도

선택 기간의 시도별 누계 위에 전입(빨강)·전출(파랑) 지도 두 개를 표시합니다. 표와 동일한 집계값을 사용하며 기간·연령·성별 변경 시 함께 갱신됩니다. 인원이 많을수록 진해지는 선형 색상 척도이며, 양쪽 지도는 전입·전출 전체에서 구한 공통 최댓값을 사용합니다. 실제 0명은 가장 옅은 색, 미확인·누락값은 회색, 집계 대상인 제주는 별도 중립색입니다.

마우스·터치·키보드 또는 지도별 지역 선택 상자로 지역을 선택하면 두 지도에서 같은 지역의 수치를 함께 확인합니다. 모바일에서는 지도를 세로로 배치합니다. 기존 표와 CSV는 유지합니다.

지도는 2026년 10월 1일 시도 경계로 표시하며 광주·전남은 통합 기준으로 합산합니다. 외부 지도 API·타일 서버·지도 인증키를 사용하지 않습니다. `map-regions.js`에 경량 SVG 경로를, `region-map.js`에 색상 계산과 렌더링을 저장합니다. 두 파일도 HTML과 함께 배포하고, 파일 변경 시 HTML의 해당 스크립트 URL에 붙인 `v` 값을 SHA-256 앞 12자리로 갱신하세요.

지도 데이터는 통계청 SGIS / vuski/admdongkor, CC BY 4.0입니다. 출처·고정 버전·가공 내역은 [assets/MAP-SOURCE.md](assets/MAP-SOURCE.md), 원본 라이선스는 [assets/MAP-DATA-LICENSE.txt](assets/MAP-DATA-LICENSE.txt)에 보존했습니다.

## 적용 순서

1. [apps-script/Code.gs](apps-script/Code.gs)의 **전체 내용**으로 Apps Script의 기존 `Code.gs`를 교체하고 저장합니다. 기존 스크립트 속성 `DATA_GO_KR_SERVICE_KEY`는 그대로 사용하며 키를 HTML에 넣지 않습니다. 이전에 저장한 `JEJU_MERGED_REGION`도 유지합니다. 없다면 이미 확인된 코드 12를 사용하므로 코드 탐색을 다시 실행할 필요가 없습니다.
2. 편집기에서 `testApi`를 실행하고 연령대별 `inboundAgeBands`/`outboundAgeBands`를 확인합니다. 각 배열은 `[남성, 여성]`입니다. 누락 필드는 `null`입니다.
3. **배포 → 배포 관리 → 대시보드에 연결된 배포의 수정 → 새 버전 → 배포**를 선택합니다. 기존 웹 앱 URL을 유지합니다.
4. 기존 `/exec?action=health`에서 `version: "jeju-youth1939-20261106-v7"`, `features: ["ageBands", "youth1939"]`를 확인합니다.
5. `index.html`, `theme.css`, `month-dial.js`, `comparison.js`, `migration.js`, `map-regions.js`, `region-map.js`, `assets/`를 함께 GitHub Pages 소스에 반영합니다. 모든 파일이 필요합니다. `migration.js`를 수정하면 `index.html`의 스크립트 URL에 붙인 `v` 값도 파일의 SHA-256 앞 12자리로 갱신합니다. 브라우저가 이전 계산 코드를 재사용하지 않도록 하기 위한 버전입니다. 웹 앱 주소를 바꾼 경우 `index.html`의 `DEFAULT_ENDPOINT`도 변경해야 합니다. 예전에 브라우저에 저장된 연결 주소는 사용하지 않고 현재 배포의 기본 주소를 사용합니다.
6. 대시보드에서 2026년 9월/전체 연령/전체 성별을 조회합니다. 기존 검증 기준은 15개 지역, 전입 1,878명·전출 2,099명·순이동 -221명입니다. 이후 10대/90대와 연간 조회를 확인합니다.

Apps Script 편집기 조작과 웹 앱 배포는 별도 권한이 필요하며, 저장소를 푸시하는 것만으로 Apps Script가 업데이트되지는 않습니다. 기존 v5 서버는 전체 연령·청년층은 반환하지만 새 `ageBands`가 없어 10대~90대 값이 비워집니다. 청년(19~39세)에는 v7의 `youth1939` 필드도 필요합니다.

## 요청과 성능

대시보드는 Apps Script에 월마다 `month=YYYYMM&callback=jejuCb_…`를 요청합니다. 서버는 공공데이터 API에 각 지역 쌍의 `mvinAdmmCd`, `mvtAdmmCd`, `srchFrYm`, `srchToYm`, `lv=1`, `type=json`, `numOfRows=10`, `pageNo=1`, `serviceKey`를 보냅니다. 날짜 범위는 한 달이며 연령 필드는 응답에서 합산합니다.

기간 조회는 선택한 월을 순차 요청합니다. 각 월은 서버 캐시가 없을 때 공공데이터 API 기준 30~32건이 필요합니다. 기간이 길수록 최초 조회 시간이 길어집니다. 서버는 완전한 월 결과를 6시간, 부분 자료를 10분 캐시하고, 브라우저는 정상 월 결과를 5분 재사용합니다. 서버 캐시는 보존이 보장되지 않습니다. 진행 상황과 중단 버튼을 제공합니다. 실패한 월은 자동 반복하지 않고, 다시 조회하면 정상 월 캐시는 재사용하고 실패한 월을 재조회합니다.

## 로컬 실행과 검증

별도 설치·빌드가 필요하지 않습니다. 기존 격리 체크아웃을 사용하며 별도 Git worktree를 만들 필요가 없습니다.

```sh
cd /workspace/jeju-migration-dashboard
python3 -m http.server 8000 --bind 127.0.0.1
```

별도 터미널에서:

```sh
cd /workspace/jeju-migration-dashboard
node tests/calculations.test.cjs
node tests/browser.cjs
node tests/comparison-browser.cjs
```

계산 테스트는 Node 기본 기능만 사용합니다. 기본 조회에서 선택 기간만 요청하는지, 선택형 2·3개년 비교가 정확한지, 연도 경계·역전 기간 차단·CSV 범위도 검사합니다. 브라우저 테스트는 실행 환경에 제공된 Playwright와 `/usr/bin/chromium`을 사용하며 로컬 서버가 필요합니다. 테스트는 실제 통계와 구별되는 모의 응답으로 연령대 경계·성별·누락 월·통합 전후 합산·캐시·취소·CSV·모바일 표시를 확인합니다. 실제 응답 검증 결과는 위의 청년 기준 항목에 기록했습니다.
